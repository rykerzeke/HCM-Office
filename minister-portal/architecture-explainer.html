SYS.01 // Architecture Explainer

Minister's Request Portal

A comprehensive civic response system built to manage and track citizen grievances, policy requests, and meetings for the central administration.

OVERVIEW: CORE TECHNOLOGIES

Frontend Layer

A reactive citizen & admin portal.

  • Vite
  • React
  • TypeScript
  • Tailwind CSS

Backend API

High-performance, secure transaction processing.

  • Node.js
  • Fastify
  • Prisma ORM
  • Supabase PostgreSQL

BACKEND MODULES (HYBRID DETAIL)

src/routes/cases.ts

The lifecycle engine for citizen requests. Handles state transitions.

Action Status Change
Submit Request PENDING_APPROVAL
Office Review APPROVED / ON_HOLD / REJECTED
Assign Date SCHEDULED
Post-Meeting COMPLETED / FOLLOW_UP_REQUIRED

src/routes/assignments.ts

Task delegation system. Links cases to specific staff members.

  • Creates Tasks
  • Tracks Due Dates
  • AssignmentStatus (PENDING -> RESOLVED)

src/data/prisma.ts

The database connection manager. Utilizes DATABASE_URL for the connection string via PgBouncer (Port 6543).

Note: DIRECT_URL (Port 5432) is isolated solely for Prisma Migrations.

src/middleware/

Security and Request Validation layer.

  • authenticate (JWT Verification)
  • authorize (RBAC / requireAdmin)
